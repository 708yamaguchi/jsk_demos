take_out_trashbag
=================

# Setup

1. Prepare a garbage bag and a string to tie it. The length of the string should be slightly longer than the circumference of the trash can. (This time 1300mm)

   ![garbage_bag_size](https://user-images.githubusercontent.com/19769486/178923345-82e03ba5-e2bb-4695-a2dc-81c1d289b870.jpg)

2. Punch a hole (red dots) in a garbage bag.

   <img src="https://user-images.githubusercontent.com/19769486/178926499-e9f40388-6f53-454b-a525-8f30641a8e2a.png">
   <img src="https://user-images.githubusercontent.com/19769486/178924812-54425f44-ca7b-4b19-85eb-e82cd4584d35.png">

3. Thread the string alternately through the inside and outside of the trash bag. Then staple the string.

   <img src="https://user-images.githubusercontent.com/19769486/178924802-ebcb9632-4367-45e1-a884-86d193b0129f.png">
   <img src="https://user-images.githubusercontent.com/19769486/178925333-ceb250c5-f9a7-4996-ab3e-c468d1b4bad5.png">

4. Set trash bag and handle on trash box. Be careful that the trash bag does not cover the green tape for recognition.

   <img src="https://user-images.githubusercontent.com/19769486/178924832-a69713ca-4b44-4e1f-baa1-8b454eac6466.png">
   <img src="https://user-images.githubusercontent.com/19769486/178925160-babb8f37-f760-43b8-bd8b-7451fba0b4f7.png">
